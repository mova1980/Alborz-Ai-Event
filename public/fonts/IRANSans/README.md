# IRANSans

اگر مدام در پوشه `Modam` نباشد، سایت از ایران‌سنس این پوشه می‌خواند.

نام‌های مورد انتظار:

- `IRANSans-Regular.woff2` (400)
- `IRANSans-Medium.woff2` (500)
- `IRANSans-Bold.woff2` (700)
- `IRANSans-Light.woff2` (300)

نام‌های جایگزین پذیرفته‌شده: `IranSans-*.woff2`, `IRANSansX-*.woff2`
