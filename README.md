## فونت فارسی

فایل‌ها را اینجا بگذارید — بدون تغییر کد خوانده می‌شوند:

1. `public/fonts/Modam/` — اولویت اول  
   نام‌ها: `Modam-Regular.woff2`, `Modam-Medium.woff2`, `Modam-SemiBold.woff2`, `Modam-Bold.woff2`, `Modam-ExtraBold.woff2`, `Modam-Black.woff2`
2. `public/fonts/IRANSans/` — اگر مدام نباشد  
   نام‌ها: `IRANSans-Regular.woff2`, `IRANSans-Medium.woff2`, `IRANSans-Bold.woff2`

تا وقتی این فایل‌ها نرسند، Vazirmatn لود می‌شود.

فونت انگلیسی نمایش: **Syne** — بدن: **Outfit**.
